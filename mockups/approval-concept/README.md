# construct.da mockups

Static concept prototype for the approved light-theme construct.da direction.

## Files
- `index.html` — prototype shell with landing, intake wizard, and advisory dashboard
- `styles.css` — shared light-theme visual system
- `script.js` — simple screen switching, intake progression, and dashboard filtering

## Open locally
Option 1:
- open `index.html` directly in a browser

Option 2:
- from this folder run:

```bash
python3 -m http.server 8123
```

Then open `http://localhost:8123`.
